# 三 Agent 多工具操作手册

> 适用：`XXX升级项目` 下的 3 个 agent（调度 / 系统初始化 / ATC 检查）在各类 AI 工具中的使用。
> 共同前提：Node.js ≥ 16、MCP 服务器 `adt-dev`、连接配置 `.env`（见 `docs\部署文档.md` §3-4）。

## 0. 速查表

| 工具 | MCP 配置来源 | Agent 指令加载 | 推荐用法 |
|---|---|---|---|
| **VS Code (Copilot)** | `.vscode\mcp.json`（自动提示） | `AGENTS.md`（自动） | 打开 `.code-workspace` → Run Task / 对话 |
| **Cursor** | `agent-configs\cursor.json` | `AGENTS.md` / `.cursor\rules` | 打开项目 → 对话执行 |
| **Windsurf** | `agent-configs\windsurf.json` | `AGENTS.md`（自动） | 打开项目 → 对话执行 |
| **Claude Code (CLI)** | `claude mcp add` / `claude-code.json` | `CLAUDE.md` + `AGENTS.md` | `claude` 进入项目 → 对话执行 |
| **Claude Desktop** | `claude-desktop.json`（贴入配置） | 无文件指令 → 粘贴提示词 | 对话粘贴执行 |
| **Cline** | `cline.json`（Cline 设置） | 无自动指令 → 粘贴提示词 | 对话粘贴执行 |
| **通用 MCP 客户端** | `other-agents.json` | 粘贴 AGENT.md 全文 | 对话粘贴执行 |
| **HTTP 远程模式** | `http-remote.json` + `start-http.cmd` | 各客户端自行加载 | 多客户端共享一个 MCP 服务 |

## 1. 通用前置（所有工具）

1. **准备连接**：确认 `.env` 存在且可连（`your-abap-mcp\mcp-pack\.env`，或初始化 agent 生成）。
2. **准备 MCP 服务器**：`adt-dev\dist\server\launcher.js` 存在。
3. **决定"配置来源"**：本机直接用 `.vscode\mcp.json`（真实路径）；分发给别人时用 `agent-configs\<工具>.json` 模板（路径为占位符，需替换为实际 launcher/env）。
4. **拉取/使用 agent 指令**：三个入口文档
   - 调度：`agent-scheduler\AGENT.md`
   - 初始化：`agent-system_initialization\docs\SYSTEM_INIT_AGENT.md`
   - ATC：`agent-ATC_check\AGENT.md`
   - 总览：`AGENTS.md`

## 2. 各工具操作

### 2.1 VS Code（推荐入口）
1. `文件 → 打开工作区`，选 `XXX升级项目.code-workspace`。
2. 首次打开 VSCode 提示"是否允许工作区中的 MCP 服务器"，点 **允许**（来自 `.vscode\mcp.json`）。
3. **Run Task**：`终端 → 运行任务`，选常用操作（重跑 ATC / 拉历史 / HTML / 部署校验 / 回归断言 / 候选补丁 / 调度自检），参数用输入框默认值。
4. **对话（Copilot）**：新对话中输入执行提示词（见 §3），Copilot 自动读取 `AGENTS.md` 与各 `AGENT.md`。

### 2.2 Cursor
1. 打开 `XXX升级项目` 文件夹。
2. **MCP**：`Settings → MCP → Add new MCP Server`，粘贴 `agent-configs\cursor.json` 的 `mcpServers` 内容，替换占位路径为实际 launcher/env。
3. **指令**：Cursor 自动读 `AGENTS.md`；也可把 `agent-ATC_check\AGENT.md` 拷到 `.cursor\rules\atc-agent.mdc` 常驻。
4. 对话中输入执行提示词（§3）。

### 2.3 Windsurf
1. 打开项目文件夹。
2. **MCP**：`Settings → MCP`，粘贴 `windsurf.json` 的 `mcpServers`（替换路径）。
3. 自动读 `AGENTS.md`；对话执行（§3）。

### 2.4 Claude Code（CLI）
```bash
cd C:\path\to\XXX升级项目
# 注册 MCP（一次性）：
claude mcp add mcp-abap-adt -- node C:/.../adt-dev/dist/server/launcher.js --env-path=C:/.../mcp-pack/.env
# 或导入 agent-configs/claude-code.json 的配置
claude
```
1. Claude Code 自动读 `CLAUDE.md` 与 `AGENTS.md`。
2. 对话中输入执行提示词（§3）；Claude Code 支持 subagent，调度会按方式 A 委派。

### 2.5 Claude Desktop
1. `设置 → 开发者 → 编辑配置`，打开 `claude_desktop_config.json`，把 `claude-desktop.json` 的 `mcpServers` 合并进去（替换占位路径），重启应用。
2. 无文件指令自动加载 → 新对话**粘贴执行提示词**（§3，含入口文档路径，让 Claude 自行读取）。

### 2.6 Cline
1. 打开项目文件夹。
2. `Cline 设置 → MCP Servers → Add`，粘贴 `cline.json` 的配置（替换路径），状态变绿即可。
3. Cline 无自动指令加载 → 对话中粘贴执行提示词（§3）。

### 2.7 通用 MCP 客户端（其他 agent）
1. 用 `other-agents.json` 的配置注册 MCP 服务器（含 `--exposition=readonly,high,customizing,debug`）。
2. 对话中粘贴执行提示词（§3）或直接引用 `AGENTS.md` 让模型读取。

### 2.8 HTTP 远程模式（多客户端共享）
1. 运行 `agent-system_initialization\mcp-pack\scripts\start-http.cmd`（端口 3000，已注入 `SAP_RFC_BACKEND=soap`）。
2. 各客户端用 `http-remote.json` 的 URL 型配置（`http://127.0.0.1:3000/mcp/stream/http`）接入同一个 MCP 服务。
3. 指令加载方式同各自工具。

### 2.9 多系统（开发/生产）
- 用 `multi-system.json` 模板注册 `mcp-abap-dev` / `mcp-abap-prod` 两个服务器（各自 `--env-path` 指向 `dev.env` / `prod.env`）；使用前在 `mcp-pack\` 自备两份 env。

## 3. 执行提示词模板（各工具通用，粘贴/输入）

### 3.1 完整 ATC 检查（推荐）
```
请读取 C:\path\to\XXX升级项目\AGENTS.md 与 agent-ATC_check\AGENT.md，
按其中"8 步流程"执行一次 ATC 检查与整改。

本次参数：
- 连接：<.env 路径，如 C:\path\to\your-abap-mcp\mcp-pack\.env>
- ATC 变体：ZABAP_CLOUD_DEV_CHECK
- 创建人账号：123456
- 项目目录：<如 C:\path\to\XXX升级项目\ATC-work>
- 传输：<复用 ZZTR000001 或提供>
- 执行模式：interactive（每个确认点暂停问我）

遇到以下情况请暂停向我确认：连接/传输确认、步骤 4 勾选检查项、步骤 6 修改前 diff、不可修项处理。
```

### 3.2 仅拉取报告（不改代码）
```
请读取 agent-ATC_check\AGENT.md 步骤 2，按变体 ZABAP_CLOUD_DEV_CHECK 重跑 ATC
并生成 HTML 汇总报告到 <项目目录>；不要修改任何代码。
```

### 3.3 调度一轮（初始化一次 + ATC）
```
请读取 agent-scheduler\AGENT.md，对项目 <projectKey>（如 XXX-ZZZ-ZZZPROG001）执行一轮调度：
先检查/初始化（每个项目只执行一次），再委派 ATC 检查。参数：连接=<.env>，变体=…，创建人=…，传输=…。
```

### 3.4 仅初始化
```
请读取 agent-system_initialization\docs\SYSTEM_INIT_AGENT.md，完成本机 SAP MCP 连接初始化
（探测 → .env → agent-configs → 验证，只读验证即可，不建测试对象）。
```

## 4. 执行确认点（所有工具一致）

| 阶段 | 确认内容 |
|---|---|
| 开始 | 连接 / 变体 / 创建人 / 项目目录 / 传输 |
| 步骤 4 | 勾选要 AI 处理的检查名（多选） |
| 步骤 6 | 修改前 Before/After diff 展示后确认 |
| 步骤 7 | 传输号、修复策略（交互模式逐处确认；batch 模式自动） |
| 收尾 | 回归断言结果与剩余项原因 |

## 5. 常见问题

| 现象 | 处理 |
|---|---|
| 工具连不上 MCP | 检查 launcher/env 路径（用真实路径替换占位符）；重启工具；自签名证书已设 `NODE_TLS_REJECT_UNAUTHORIZED=0` |
| 文本池工具报错 | 确认 `env` 里 `SAP_RFC_BACKEND=soap`（模板已带） |
| AI 不读指令文档 | 用 §3 提示词显式给出入口文档路径；或把 `AGENT.md` 拷成工具支持的规则文件（Cursor `.cursor\rules` / Claude Code `CLAUDE.md`） |
| 多客户端抢同一会话 | 用 HTTP 远程模式（§2.8）共享一个服务 |
